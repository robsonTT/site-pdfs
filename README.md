# 📄 site-pdfs

Um site simples, rápido e gratuito para **visualizar, enviar e excluir PDFs diretamente pelo navegador** — hospedado na Vercel.  
✅ Sem banco de dados, 100% baseado em arquivos.  
🌐 Acesse: [site-pdfs.vercel.app](https://site-pdfs.vercel.app)

---

## 🔧 Funcionalidades

- 🔍 **Pesquisa por nome** dos PDFs
- ➕ **Upload de novos PDFs**
- ❌ **Exclusão de PDFs**
- 📖 **Visualização embutida** no navegador (sem baixar)

---

## 🚀 Tecnologias Utilizadas

- **Frontend**: HTML + JavaScript Vanilla
- **Backend**: Node.js com Express
- **Upload**: Multer
- **Hospedagem**: [Vercel](https://vercel.com) (gratuito)
- **Armazenamento**: Diretório local `/pdfs`

---

## 🖥️ Como rodar localmente

```bash
git clone https://github.com/seu-usuario/site-pdfs.git
cd site-pdfs
npm install
mkdir pdfs
node server.js
